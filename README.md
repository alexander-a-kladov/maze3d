# Maze OpenGL

3D-движок прохождения лабиринта на Python + OpenGL.

## Управление

- `W` — движение вперёд
- `S` — движение назад
- `A` — поворот влево
- `D` — поворот вправо
- `R` — рестарт после достижения финиша
- `ESC` — выход

Клавиши работают именно как WASD, а не как стрелки.

## Формат maze.txt

- `w` — стена
- `e` — финиш
- `s` — старт
- пробел — обычный пол

Пробелы в файле значимы, поэтому не форматируйте строки через `.strip()`.

## Ресурсы

Положите:

- `textures/w.png` — текстура стен
- `textures/f.png` — текстура пола и финишной метки
- `sounds/walk.wav` — звук шага

Если файлов текстур/звука нет, программа запускается с временными текстурами/без звука.

## Установка

```bash
python -m pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Размер клетки лабиринта — 2x2 мировых единицы, шаг игрока — 1 мировая единица.
Стены имеют высоту 2 мировые единицы. Камера находится на уровне глаз игрока.
